طريقة تثبيت التطبيق على Galaxy

  1. افتح رابط التطبيق المنشور على اتصال HTTPS باستخدام Chrome أو Samsung Internet.
  2. من قائمة المتصفح اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
  3. افتح الأيقونة من الشاشة الرئيسية؛ وبعد أول تحميل يمكن تشغيل الواجهة دون اتصال.
  4. استخدم «نسخة احتياطية» لحفظ نسخة JSON في مكان آمن، ولا تعتبرها نسخة مشفرة.
هذه الحزمة ملفات تطبيق ويب تقدمي (PWA)، وليست ملف APK أصلياً. تحتاج إلى نشر الملفات على رابط HTTPS أول مرة كي تظهر إمكانية التثبيت.

وظائف تعمل في هذه النسخة

  • إنشاء القضايا وتحرير بياناتها محلياً.
  • حفظ الصور الأصلية في قاعدة بيانات المتصفح مع حساب بصمة SHA-256 عند دعم المتصفح لذلك.
  • إدخال القياسات يدوياً مع الوحدة والطريقة والمصدر.
  • إضافة رموز وعناصر يدوية إلى مخطط ثنائي الأبعاد توضيحي.
  • تسجيل أحداث المستخدم وإصدارات تجريبية، وتصدير المخطط SVG وملف نسخ احتياطي JSON.
  • طباعة تقرير القضية أو حفظه PDF من نافذة الطباعة في الهاتف.

وظائف تحتاج إلى مرحلة تطوير تالية

  • مصادقة حقيقية وصلاحيات من خادم مركزي وسجل تدقيق غير قابل للتلاعب.
  • خادم Python/FastAPI وقاعدة PostgreSQL ومخزن ملفات منفصل ونسخ احتياطي مؤسسي.
  • OpenCV لتحليل جودة الصور والمعايرة والتحويل الهندسي بعد توفير نقاط مرجعية سليمة.
  • نموذج YOLO/Ultralytics محدد الإصدار والأوزان والترخيص ومدرب ومختبر على بيانات مصرح بها.
  • تحقق ميداني وقانوني وأمني، واختبارات قبول وتوثيق سلسلة حيازة معتمد.
لا تستخدم هذا النموذج لحفظ أدلة أو بيانات شخصية أو ملفات قضايا حقيقية. التخزين محلي وغير مشفر، ويمكن فقدانه عند مسح بيانات المتصفح أو تغيير الجهاز. البصمة الرقمية وحدها لا تثبت سلسلة الحيازة ولا تمنع التلاعب.

التقنيات في التصميم المستهدف

واجهة عربية متجاوبة (يمكن تطويرها لاحقاً بـ React) ← API بخادم Python/FastAPI ← PostgreSQL لبيانات القضايا + مخزن ملفات للأصول ← OpenCV للمعالجة الهندسية ← نموذج كشف معتمد بعد اختبار الترخيص والبيانات. الصيغ المستهدفة: SVG للمخطط وPDF للتقرير، وSHA-256 لبصمة الملفات.
