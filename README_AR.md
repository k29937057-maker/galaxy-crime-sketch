# نظام الكروكي الجنائي — Android 2.1 التجريبي

هذا مشروع Android Studio أصلي (Kotlin + WebView محلي) يغلّف واجهة الكروكي الحالية داخل تطبيق Android مستقل. ملفات HTML وJavaScript والصور مضمّنة داخل `app/src/main/assets` ولا يحتاج تشغيل الواجهة إلى استضافة ويب.

## ما الذي أضيف في غلاف Android؟

- تشغيل الواجهة من ملفات مضمّنة داخل التطبيق عبر أصل HTTPS محلي خاص بـ WebView، مع تعطيل الوصول إلى المواقع الخارجية.
- تفعيل DOM Storage وIndexedDB حتى يعمل التخزين المحلي للبيانات والصور.
- فتح منتقي ملفات Android لاختيار صور القضية أو ملف النسخة الاحتياطية.
- حفظ تصدير SVG ونسخة JSON الاحتياطية عبر نافذة «حفظ باسم» في Android.
- إرسال تقرير القضية إلى خدمة الطباعة في Android؛ ويمكن اختيار «حفظ PDF» من نافذة الطباعة إن كانت الخدمة متاحة.
- لا يطلب التطبيق صلاحية الوصول العام إلى ملفات الهاتف؛ استخدام الملفات يتم من خلال منتقي النظام.

## بناء APK على جهاز كمبيوتر

1. ثبّت Android Studio مع Android SDK Platform 35 وJDK 17.
2. افتح مجلد `GalaxyCrimeSketch` في Android Studio (المجلد الذي يحتوي `settings.gradle`).
3. اسمح بمزامنة Gradle وتنزيل إضافات Android Gradle Plugin وKotlin من مستودعات Google وMaven Central.
4. اختر `Build > Build Bundle(s) / APK(s) > Build APK(s)`.
5. ملف الاختبار الناتج يكون عادةً في `app/build/outputs/apk/debug/app-debug.apk`.

للتثبيت المباشر على هاتف Galaxy، انقل ملف APK الناتج إلى الهاتف وافتحه، واسمح بالتثبيت من المصدر الذي فتحت منه الملف عند طلب Android ذلك. لا ترفع نسخة debug إلى متجر Play. يلزم توقيع release مستقل قبل أي توزيع رسمي.

## حدود الإصدار الحالية — مهمة جداً

هذه نسخة تجريبية محلية وليست نظاماً جنائياً معتمداً. الغلاف الأصلي لا يحوّل التخزين المحلي إلى قاعدة بيانات مركزية، ولا يضيف حسابات دخول أو صلاحيات مؤسسية حقيقية. اختيار الدور داخل الواجهة الحالية توضيحي فقط، وسجل الأحداث والإصدارات قابل للتعديل من داخل بيانات التطبيق. لا يوجد نموذج ذكاء اصطناعي أو OpenCV أو YOLO مضمّن، ولا معايرة مقياس هندسية معتمدة أو تحويل منظور/إحداثيات.

كما أن بيانات التطبيق محفوظة محلياً في مساحة WebView وليست مشفرة تشفيراً جنائياً مستقلاً. لا تستخدم هذا الإصدار لحفظ أسماء أو صور أو معلومات قضايا حقيقية أو سرية قبل تنفيذ الخادم وقاعدة البيانات والتشفير وإدارة الصلاحيات والتدقيق المؤسسي والاختبارات الأمنية المطلوبة في التقارير.

## اختبار الوظائف بعد التثبيت

- إنشاء قضية تجريبية باسم وبيانات غير حقيقية.
- إرفاق صورة تجريبية من منتقي ملفات الهاتف.
- إضافة قياس وعنصر إلى الرسم.
- تصدير SVG والتحقق من ظهور نافذة حفظ Android.
- إنشاء نسخة JSON احتياطية ثم استيرادها.
- اختيار طباعة التقرير ثم «Save as PDF» إذا ظهرت خدمة الطباعة.
- إغلاق التطبيق وإعادة فتحه للتأكد من بقاء البيانات التجريبية.

## متطلبات البناء

- Android Gradle Plugin 8.7.3
- Kotlin Android Plugin 2.0.21
- Gradle 8.9 أو إصدار متوافق مع Android Gradle Plugin
- JDK 17
- Android SDK Platform 35

لم يتم تضمين APK جاهز في هذه الحزمة؛ بيئة إنشاء الحزمة لم تتوفر فيها Android SDK أو Gradle أو أدوات توقيع APK، كما أن الوصول إلى مستودعات تنزيلها غير متاح. لذلك لم أدّعِ نجاح بناء APK أو اختباره على جهاز Galaxy.
